PROYECTO: Soluciones Administrativas en Salud Laboral

INSTRUCCIONES DE USO:
1. Asegúrate de tener Python instalado.
2. Abre una terminal en esta carpeta.
3. Instala las dependencias: pip install -r requirements.txt
4. Ejecuta la aplicación: python app.py
5. Abre tu navegador en: http://127.0.0.1:5000

IMPORTANTE:
- Coloca el archivo 'logo.jpg' dentro de la carpeta 'static/img/'.
- Modifica los enlaces de WhatsApp e Instagram en 'templates/index.html' con tus datos reales.
